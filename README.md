# FrameStudio - E-Commerce Web Platform

Full-stack e-commerce platform for custom and artisanal frames.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, Font Awesome, Chart.js
- **Backend:** Python Flask (REST APIs)
- **Database & Auth:** Supabase PostgreSQL, Supabase Auth, Supabase Storage
- **Payments:** Direct Merchant GPay QR & Cash on Delivery (COD)
